# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's private vulnerability reporting: open the
repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue,
pull request or discussion for a security problem.

Include what is affected (crate, migration, workflow or app platform), the steps to reproduce
with synthetic data, and the impact you expect. Do not include real customer records,
credentials or tokens in the report.

## Scope

This repository is a development rebuild that runs on synthetic data. Reports about the
authority's role checks (Owner and Manager), the device's stored credentials and projection,
the app's command authorization, and anything that could expose costs, buy rates or margins to a
Manager are especially welcome.
