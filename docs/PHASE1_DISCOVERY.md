- [ ] Before navigation, use a fresh disposable browser profile/context and an origin distinct from the laptop deployment. Serve only the unchanged HTML on loopback. Block external network at the environment boundary, deny requests outside the loopback allowlist, block service workers, and intercept popup, external protocol, file-share and printer actions. - [ ] Confirm empty localStorage/IndexedDB, no saved folder handles, no Google/Supabase/WhatsApp sessions and no live integration URLs or keys. Do not restore owner backups into the browser. Use only synthetic screens/records and inert recipients; only use a new local unsynced folder for explicit folder-backup cases. Use a fresh context for destructive actions and failure cases.
- [ ] Prepare synthetic fixture families: empty/corrupt and revision-mismatch; fractional money and Piece/Case items (tax override, cess and default-rate examples), opening stock and dated receipt lots; matched and unmatched suppliers, named and walk-in parties, duplicate-name history and opening dues; mixed-payment/credit bills, dated receipts, cancelled histories, manual godown stock and movement events. Save expected vs observed separately: source hypothesis, before/after JSON or derived controls, visible output, screenshot or export digest, allowed/blocked network evidence, and pass/fail/blocked/not-run. Mark exploratory runs as development; no installed-platform or WhatsApp acceptance from mocks.
- [ ] Expand the map by enumerating each event handler, shortcut, modal, filter, conditional/remnant branch and output by stable subcase ID.
